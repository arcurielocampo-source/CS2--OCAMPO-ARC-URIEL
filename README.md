# electricity calculator Calculator
## Description
This program calculates the electric bill
## Version 1 - Original code without input validation
- Input: Accepts a blank reading.
- Process: Calculates the electricity bill, and consumption.
- Output: the electricity bill and consumption
- Does not include input validation.
- ## Version 2 - with input validation
- input does not accept blank or zero reading/s.
- process: calculates the electricity bill, and consumption.
- output: displays the electricity bill, and consumption.
